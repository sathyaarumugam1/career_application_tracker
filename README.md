# CareerTrack

### Your job search, in one focused workspace.

CareerTrack is a full-stack job application tracker designed to turn a scattered job search into a clear, organized workflow.

From the first application to the final offer, CareerTrack keeps every opportunity in one place — so you can focus less on tracking and more on moving forward.

---

## ✦ The Idea

Job searching can quickly become a collection of spreadsheets, notes, links, and forgotten applications.

CareerTrack brings everything together into a single workspace where applications can be added, searched, filtered, updated, and monitored with ease.

**Simple to track. Easy to manage. Built for the journey.**

---

## ◌ Features

- Add and manage job applications
- Track application status
- Search by company, role, or location
- Filter applications by status
- Update application progress
- View application statistics
- Add notes for each opportunity
- Store application data persistently
- Responsive and clean user interface

---

## ✧ Application Journey

**Applied → Interview → Offer**

Applications can also be marked as **Rejected** when the hiring process ends.

## ◫ Architecture

CareerTrack follows a simple full-stack architecture:

**React Frontend**  
↓  
**REST API**  
↓  
**Express.js Backend**  
↓  
**MongoDB Database**

The frontend handles the user experience, the backend manages application data, and MongoDB provides persistent storage.

## 🚀 Getting Started

Clone the repository and install the required dependencies.

**Frontend**

`cd frontend`  
`npm install`  
`npm run dev`

**Backend**

`cd backend`  
`npm install`  
`npm run dev`

Configure your MongoDB connection locally using an environment variable before starting the backend.
